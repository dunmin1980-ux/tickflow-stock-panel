The following lines are exact semantic excerpts from the official Responses
API parameter reference. The snapshot contains no account or credential data.

text.format.type
输出格式类型。可选值：text、json_schema、json_object。

json_object / json_schema 能力尚在 beta 阶段，请谨慎在生产环境使用。

text.format.schema
JSON Schema 定义。当 type 为 json_schema 时必填。

text.format.strict
仅当 type 为 json_schema 时生效。

INTERPRETATION BOUNDARY
This page proves the Responses API exposes json_schema parameters. It does not
override the model-specific capability table and does not prove that every
model supports structured output.
